## Tables

Generate all script-backed paper tables with:

```bash
cd /vol/bitbucket/fr920/ArgCausalDisco-worktrees/llm-uai2026-freeze
python scripts/paper_tables.py --tag g2a01
```

During long runs, this can be checked without failing on missing inputs:

```bash
python scripts/paper_tables.py --tag g2a01 --allow-missing
```

Outputs are written to `results/tables/` as `.csv`, `.md`, and `.tex` where applicable. The source manifest is:

```text
results/tables/paper_table_sources_g2a01.csv
```

The old GPT comparison entry point now delegates to the same table generator:

```bash
python scripts/comparison_table.py --tag g2a01
```

## Refresh Order

After all experiment jobs finish:

```bash
cd /vol/bitbucket/fr920/ArgCausalDisco-worktrees/llm-uai2026-freeze
python scripts/paper_tables.py --tag g2a01
```

Then execute notebooks in this order. Use `SAVE_FIGS=1` when you want the Plotly helper outputs written under `results/figs/`; omit it for a display-only refresh.

```bash
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_causenet_desc.ipynb --inplace
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_bnlearn_desc.ipynb --inplace
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_causenet.ipynb --inplace
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_bnlearn.ipynb --inplace
jupyter nbconvert --to notebook --execute notebooks/gpt_ablation.ipynb --inplace
```

If a notebook needs manual inspection instead of batch execution, run the same notebooks interactively from top to bottom. The first source cell in each notebook prints missing refreshed inputs before plotting.
