## Tables

Generate the numbered camera-ready paper tables with:

```bash
cd /vol/bitbucket/fr920/ArgCausalDisco-worktrees/llm-uai2026-freeze
python scripts/final_paper_tables.py --tag g2a01
```

Final outputs are written to `results/tables/final/` as `.md` and `.tex` files, with companion check tables where applicable. The final generator is a presentation layer over `scripts/paper_tables.py`, which remains the reusable result-loading, summary, and statistics layer.

For broader diagnostic and intermediate tables, run:

```bash
python scripts/paper_tables.py --tag g2a01
```

The intermediate source manifest is:

```text
results/tables/paper_table_sources_g2a01.csv
```

The GPT/Gemini comparison table is also available through the compatibility entry point:

```bash
python scripts/comparison_table.py --tag g2a01
```

## Notebook Execution

Execute notebooks in this order. Use `SAVE_FIGS=1` when figure files should be written under `results/figs/`.

```bash
cd /vol/bitbucket/fr920/ArgCausalDisco-worktrees/llm-uai2026-freeze
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_causenet_desc.ipynb --inplace
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_bnlearn_desc.ipynb --inplace
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_causenet.ipynb --inplace
SAVE_FIGS=1 jupyter nbconvert --to notebook --execute notebooks/experiments_bnlearn.ipynb --inplace
jupyter nbconvert --to notebook --execute notebooks/gpt_ablation.ipynb --inplace
```

For manual inspection, run the same notebooks interactively from top to bottom.

## Empty Consensus Priors

Description-based Gemini has one empty consensus prior:

```text
dag_5_nodes_5_edges_semantics_ER
```

GPT-5-mini has more empty consensus priors. The table pipeline uses the fallback handling in `scripts/paper_tables.py` to treat empty-prior ABAPC-LLM rows as plain ABAPC fallback where a final paper table requires all-dataset coverage. The strict Gemini/GPT structural table remains the matched non-empty subset.
